## Getting Started

To use the Prolog files in this repository, you will need to have SWI-Prolog installed on your system.

### Prerequisites

- [SWI-Prolog](https://www.swi-prolog.org/)

### Installation

For detailed instructions on how to install SWI-Prolog on your operating system, please refer to the [SWI-Prolog Installation and Usage Guide](./materials/swipl_guide.md).

## Usage

To run the Prolog lab files:

1.  Start the SWI-Prolog interpreter.
2.  Load a lab file by consulting it. For example, to load the first lab:

    ```prolog
    ?- ['labs/lab01/lab01.pl'].
    ```

3.  You can now query the predicates defined in the loaded file.
